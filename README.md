# Library Management System API

RESTful API для автоматизации управления библиотекой, каталогом книг, авторами и учетом выдачи книг читателям.

## Технологический стек
* **Python 3.11** / **Django 5.x** / **Django REST Framework**
* **PostgreSQL 15** (База данных)
* **JWT (SimpleJWT)** (Аутентификация и авторизация)
* **drf-yasg** (OpenAPI / Swagger UI / ReDoc)
* **Docker & Docker Compose** (Контейнеризация)
* **Poetry** (Управление зависимостями)
